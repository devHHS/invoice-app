# invoice-app

## 한국어

인보이스·영수증을 관리하는 백엔드 프로젝트입니다.

실행: `docker compose up -d`로 PostgreSQL을 먼저 띄운 뒤, `./mvnw spring-boot:run`으로 앱을 실행합니다.

스택: Java 21 · Spring Boot · PostgreSQL · Docker

## English

A backend project for managing invoices and receipts.

Run: start PostgreSQL first with `docker compose up -d`, then run the app with `./mvnw spring-boot:run`.

Stack: Java 21 · Spring Boot · PostgreSQL · Docker
